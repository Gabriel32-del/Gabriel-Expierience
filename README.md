# Gabriel-Expierience
Una app para organizar y crear proyectos. Conecta servicios como Google Workspace para tus proyectos (Experimental)
Colabora con otros usuarios y chatea dentro de tus proyectos con la funcion Social.

# ¿De que esta hecho?
Basado en flutter, creado en la app AIDE en la play store. Creditos al creador
Usa la base de datos Supabase.
Usa Gradle 8.0 para la exportacion.

# Funciones
Puedes conectar con Google Workspace

Organiza, crea y edita proyectos 
publicos/privados.

Haz colaboraciones en proyectos grandes, con comentarios

Conecta el `ge-cli` en Linux, MacOS y Windows

Controla todo de forma `remota`

# ¿Como conecto el "Ge-Cli"?

Para conectarlo e instalarlo, haz esto:

**Instalacion** :
Linux: `apt install nodejs`
       `npm install ge-cli`

       
MacOS: 
       `brew install nodejs`
       `npm install ge-cli`


Windows: 
        `brew install nodejs`
        `npm install ge-cli`
